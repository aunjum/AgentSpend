# Limitations

- Codex JSONL is an implementation-facing format and may change.
- Claude's local JSONL schema may change and its usage is not verified API spending. Gemini import is not implemented.
- API costs, configurable prices, subscription accounting, and savings are not implemented.
- Ollama/Gemma analysis and structured recommendation validation are not implemented.
- Dashboard is one-shot text, not a resize-aware TUI.
- Watch uses periodic rescans rather than filesystem notifications.
- No real-world end-to-end collection has been verified yet.
